# 漫剧制作工作流

在节点库选择「漫剧」，或从「常用流程 → 漫剧制作」创建已连接的梗概、剧本、角色参考和分镜节点。模板只创建本机节点与连线。

新手可按「写故事 → 拆解漫剧剧本 → 下一步：做分镜 → 输出镜头节点」操作。连接素材后自动读取上游，素材更换、生成模型和镜头细节可按需展开；不必先填写全部参数。模型选择沿用现有配置并显示分组，不能使用的模型会提示重新配置，不会悄悄换模型。

1. 在文本节点填写梗概、目标集数、每集时长和画风要求，连接「漫剧剧本」，选择已配置的文本模型后点击「拆解漫剧剧本」。结果包含分集标题、概要、可拍摄的场景动作与对白、结尾钩子，以及角色的固定外形、性格和声音设定。
2. 选择要制作的分集，直接修改剧本；可输出该集为普通文本节点供其他扩展复用。点击「下一步：做分镜」会复用已连接的分镜；没有时创建分镜和角色参考，并带入剧本角色设定。角色节点可连接文本、剧本或原图，点击「AI 整理角色」补全外形、服装和画风，也可手工填写；「下一步：做角色图」创建已连接的生图节点，再由用户点击生成。
3. 「漫剧分镜」读取所选分集与角色参考。模型拆镜后，可修改镜头顺序、场景、出镜人物、景别、画面提示词、台词、参考时长、运镜及连续性说明，也可手工添加和删除镜头。
4. 点击「输出镜头节点（不自动生成）」创建逐镜的文字、画面、视频及有台词镜头的音频节点。角色参考连接到对应画面和视频；画面生成提示词与对白分开，视频保留对白和参考时长。音频生成后可作为视频参考，是否支持取决于所选视频模型；也可使用既有混音或智能剪辑节点手动编排。
5. 需要连续出图时，点击「转为批量任务」。每个镜头保持一条画面提示词和角色参考；开始前显示总任务数并确认，每次执行一项，失败暂停。已保存任务沿用原回执恢复，不自动重发付费请求。
6. 后期继续复用既有的结果对比、分镜板、3D 导演台、字幕、配乐混音、独立智能剪辑和原始素材导出节点。

「AI 整理提示词」仅把故事整理为可编辑的逐图草稿，生图仍需单独确认；草稿不会重复附加整篇上游文本，也可恢复原提示词。「AI 帮我选」读取所选原图并给出建议，点击「采用建议」后才改变选择，再输出原图。素材或比较要求变化后须重新比较。「AI 校对字幕」只修正文字，原字幕条数、时间轴与说话人保持不变。抠图、超分等本机工具保留离线模型，调色、拼图、混音等可直接沿用默认参数。

这些 AI 操作复用用户已配置的文本模型及准确渠道（保留 Claude 接口）；带原图时需所选模型支持视觉输入。语音识别须另选支持时间戳的识别模型，不能用普通配音模型代替。展开镜头时可在「更多设置」选画面、视频、配音模型，未指定时沿用相应默认模型，不降低分辨率或修改镜头秒数。覆盖已有角色、字幕或提示词草稿前需确认；无效模型结果、输入已更改和取消时不覆盖原内容、不自动重发。

剧本和分镜的模型调用按站点计费；重新生成覆盖当前结构前需确认，已输出节点保留。展开镜头、编辑设置、切换分集和重启均不触发生成。角色一致性、配音表现、准确视频时长由所选模型能力决定；声音设定是创作说明，不等于声音克隆。当前画布、分集和素材主要保存在本机；WebDAV 依照现有同步设置运行。

本次借鉴的公开工作流设计包括 [ComfyUI-VideoHelperSuite](https://github.com/Kosinkadink/ComfyUI-VideoHelperSuite) 的媒体组织、[WanVideoWrapper](https://github.com/kijai/ComfyUI-WanVideoWrapper) 的多模态参考、[rgthree-comfy](https://github.com/rgthree/rgthree-comfy) 的流程复用，以及 [Steerable Motion](https://github.com/banodoco/Steerable-Motion) 的序列参考思路。实现使用 Canvas 原生插件 API，没有打包这些项目的 ComfyUI 节点，也不要求安装 ComfyUI。

隔离回归覆盖分集解析与编辑、剧本输出、角色参考传递、模板与镜头展开不生成、批量确认和失败暂停；未调用真实付费模型进行成片质量验收。
