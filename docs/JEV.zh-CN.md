# JEV 决策节点

在「模型服务」登录 OneYes 后点击一键配置，或手动填写 TypeSafe / Jev 平台 **JEV** 分组的 Key。Canvas 会读取该分组的模型列表，当前可用模型为 `jev-latest`；仅配置和诊断不调用推理。登录态复用需要 OneYes Desktop v0.1.86 或更新版本，也可独立登录 Canvas。

一键配置按平台和分组精确匹配，为 JEV 创建或复用 `Canvas_无限画布` 专用 Key，不借用其他用途的 Key。Key 被删除、停用或更换分组时可在模型服务中诊断，再由用户点击修复；不会自动重复决策请求。

在节点库的「策划」分类添加「JEV 决策」，输入待判断内容或连接文本节点，填写问题并选择模式：

- **是非判断**：返回“是”的概率，接近 0.5 表示不确定，不强制转换成通过／不通过。
- **选择方案**：每行一个不同的候选方案，返回选中项、各方案概率和置信度。
- **标准评分**：按由低到高的顺序逐行填写评分等级，从 0 起计；返回概率加权评分、各等级概率和置信度。

点击「运行决策」会按站点规则计费，重复运行已有结果前会确认。结果和输入随画布本地保存，可点击「输出结果文本」生成文本节点；上游内容改变后需重新运行才能输出。模型概率供人工复核，不应直接当作确定事实或自动执行其他付费任务。

本次使用 Jev 原生 `POST /v1/systemone` 协议，并优先经 OneYes 直连线路与现有代理通道发出请求。JEV 不出现在普通文本、生图或视频模型列表中，不调用 Responses／Messages 文本生成协议。首版适配文本的 Choice、Score、Noul，不默认启用 TypeSafe 实验图片或长上下文功能。

失败、取消或关闭软件后不会自动重发推理；未完成时请先核对用量，再手动运行。已完成并保存的结果可以重启后查看。账户诊断和模型列表检查不会产生生成费用。

官方接口说明：[TypeSafe Quick start](https://docs.typesafe.ai/introduction/quickstart)、[System One API](https://docs.typesafe.ai/api/system-one)。
