# 模型自动同步与配置

先通过登录配置向导准备 Key，或填写自己的 OneYes Key。已有 Key 后，无需逐个添加或勾选模型：启动、返回前台、恢复网络及打开模型选择时，Canvas 自动读取该 Key 有权限访问的上游模型，按固定分组匹配生图、文本、视频、音频和 JEV 决策。也可在「设置 → 模型接入」点击「立即同步」。

同步只读取模型列表，不创建 Key、不进行试生成或重发任务。新的账户接入与创建 Key 仍使用现有配置向导。模型类型以现有名称规则自动识别，未知或特殊名称可在「管理模型 → 高级设置」调整；上游返回模型名称不代表它具备看图、听音或任意生成参数能力。

SD 2 系列的视频名称支持 fullblood、line2 等后缀与价格说明，例如 `sd-2.5-fullblood-line2`。列表和请求保留上游完整模型 ID，按所属 Key 分组选择，不把同名不同分组混为一项；SDXL 等图片模型仍按原类型处理。

## 默认模型与现有作品

当前默认模型仍可用时继续使用；缺失或未设置时自动补齐相应能力的默认模型，优先保留内置默认在实际列表中的同名项，否则采用该能力的首个可用项。默认只影响新任务，已有节点的模型 ID、分组、生成参数及分辨率保持不变。已有节点选中的模型不可用时，需要主动选择可用模型后再运行，不会静默换模型继续付费生成。

上游暂未返回的普通模型从可用选项隐藏，保留名称和设置，重新返回后恢复。手动添加的模型及自定义请求脚本会保留可用；名称没有出现在列表中并不自动证明脚本不可调用。用户主动取消勾选会保存排除偏好，同步不会重新启用；再次勾选即可恢复。自定义模型类型和脚本不会被自动识别结果覆盖。

## 缓存、断网与安全

同步复用应用原有的 30 秒查询缓存，同一连接的并行读取合并。没有新增后台轮询、超时、重试次数或生成请求。界面打开后长期停留时，可打开模型选择或点击立即同步读取最新变化。列表与偏好沿用现有配置持久化，桌面版由现有加密存储保存，重启后先使用本地配置。

断网、鉴权失败、空列表和错误格式不会清空本地模型，也不会自动创建替代 Key。单个分组失败不影响其他分组的成功同步，设置页显示失败状态，恢复网络后再次检查。更换 Key、代理或账户后，旧请求的结果不能覆盖新连接；后台同步不会重置尚未保存的模型管理编辑。

模型请求沿用既有桌面原生桥及 OneYes 固定域名；查询键和结果不保存 API Key 或代理凭据。浏览器版仍由前端直接请求接口，沿用现有存储与网络限制。

## 验证

`npm run test:models` 使用隔离 Electron 页面、真实 preload／IPC 与生产模型解析验证自动事件、默认配置、缓存、错误恢复、上下架、排除和重新勾选、后台同步不覆盖草稿，以及配置持久化。服务测试覆盖部分失败、空／损坏列表、旧连接响应隔离和自定义脚本；上游模型列表使用本机模拟，不进行真实付费调用。
