# 扩展节点的发现与组合

本轮保留已有画布、工具栏和节点接口，只优化节点入口与创作操作。

## 参考项目

| 项目 | 可借鉴的能力 | 本轮应用 |
| --- | --- | --- |
| [ComfyUI](https://github.com/Comfy-Org/ComfyUI) | 节点工作流、模板与可复用组合 | 分类搜索、输入输出说明、流程草稿 |
| [InvokeAI](https://github.com/invoke-ai/InvokeAI) | 创作素材管理与工作流组合 | 素材缩略图、原始尺寸、明确输入与结果 |
| [Jaaz](https://github.com/11cafe/jaaz) | 多模态画布与视觉分镜 | 可手动编排的分镜、转为批量任务 |

调研依据为这些公开仓库的 README；本轮没有引入它们的代码、运行时或模型依赖。

## 使用与执行边界

- 底部扩展按钮与空白处添加菜单共用节点库。名称、用途、输入输出与常用英文术语均参与搜索；Enter 添加首个结果，输入法选词时不误添加，Esc 关闭。
- 第三方扩展保持原有注册协议，不要求修改插件；未分类的插件显示在“扩展”。
- “角色参考生图”“故事分镜”“图片后期”“视频字幕配乐”是节点与连线的草稿。用户仍需填写输入、选择模型并逐项运行；不是自动执行整张图的调度器。后期工具各自产生新的媒体节点，可继续选入其他节点。
- 类型校验同时用于素材选项和执行输入；上游类型错误不静默忽略。素材缩略图只使用已有本地预览缓存，不为列表下载远端原图，也不参与处理与导出。
- 分镜支持新增、删除和排序；“转为批量任务”只生成可编辑提示词，不调用模型。分镜内换行合并成同一条，保持一镜头一项。
- 批量任务确认框和执行器使用同一提示词计算：面板文本在前，上游文本按选定顺序在后，每行一项。参考图片与角色参考继续传递到每个结果；上游文本已经拆成逐项提示词，不重复连接到每张图。
- 已有分镜或字幕在重新调用模型前提示替换；输出过的节点不受替换影响。
- 不修改并发、重试、超时或文件大小边界，不自动降低原图或视频分辨率。

## 验证

`npm --prefix web run test:oneyes` 验证搜索、分类、模板图、输入类型、逐项提示词和字幕格式。`npm run test:studio` 通过生产编译资源与原生协议验证真实节点库、键盘搜索、模板不提交请求、手工镜头与字幕操作、上游文本批量执行、原尺寸图片结果和跨进程不重发；`npm run test:creators` 保留本地处理、取消和项目隔离回归。六平台发布流程执行这些检查，使用隔离素材与模型 fixture，不发送真实付费请求。
