# Canvas 错误诊断

桌面版固定通过 HTTPS 向 `https://admin.oneyes.ai/api/canvas` 发送技术错误，独立安装也可用。开发模式和 `--smoke-test` 不访问生产诊断服务。网页独立运行时没有原生诊断桥，不上传日志。

使用随机安装 ID 和独立随机凭据，不依赖 OneYes 账户或主客户端。凭据与待上传日志保存到应用数据目录的独立 AES-GCM 文件，不调用钥匙串。同一系统用户可以读取本机加密密钥，本功能保护静态文件，不承诺防止当前用户账户已失陷。

每 60 秒合并一个不超过既有管理 API 8 KiB 请求限额的批次；网络请求最多等待同一上传周期。启动补传未完成批次，失败保留到下一周期，退出中止上传并等待本地写入，不等待网络。待上传记录最多 1000 条，超出移除最早记录；相同错误在未上传批次合并计数。服务端按安装 ID 和事件 ID 幂等入库，即使上传已成功但客户端未保存确认，也不会重复计数。升级后补传仍使用错误发生时的版本。

客户端与服务端均使用字段白名单。只记录功能模块、环节、标准错误类型、分类、已知系统错误码、HTTP 状态、来源文件名和行列号，以及应用／系统／Electron 版本和原生芯片架构。原始错误文本只用于本地分类，不持久化或上传；不采集任意上下文、用户目录、完整 URL、提示词、对话、媒体、API Key、登录凭据或 WebDAV 密码。主动取消不作为错误上报。错误堆栈只保留代码位置，不包含原始函数参数或错误消息；部分错误没有可用堆栈。

管理后台需管理员会话才能读取 `/api/admin/canvas-errors`。Canvas 安装不能读取日志，设备自报身份不授予管理权限。服务端注册使用既有接入开关和注册频率保护；日志请求使用独立安装凭据和既有每安装请求限额，不能指定他人安装 ID。后台按服务端收到时间保留 30 天，启动及每小时清理；同类问题合并显示次数和影响安装数，支持版本、系统、功能筛选及复制诊断信息。数据库备份遵循管理平台既有七天轮换。

覆盖页面异常及 React 错误、原生连接、账户／模型、图片与视频 API、异步生图提交／取图／保存、WebDAV、Agent 错误与 OTA 错误。只采集已捕获或进程退出前有机会处理的技术异常，不保证在断电、系统强杀或磁盘不可写时保存最后一条记录。日志失败不改变付费生成请求、任务重试或本地业务数据。
