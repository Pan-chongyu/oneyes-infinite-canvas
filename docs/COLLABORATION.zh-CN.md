# 局域网共同创作

桌面版 Windows、macOS、Linux 可在同一局域网共同编辑一张画布，无需部署服务器，也不依赖 OneYes 管理平台转发画布内容。

1. 房主打开要共享的画布，点击顶栏「协作 → 共享当前画布」。多网卡时选择与其他设备同网段的地址。
2. 复制完整邀请，只发送给信任的协作者。对方打开桌面 Canvas，点击「协作」，粘贴后加入。
3. 加入者会新建协作副本，原来的画布保留。各设备可共同添加、移动、修改、连接和删除节点。
4. 等待原始素材同步完成再使用素材；同步失败可点击「重试同步」。所有设备都应保留足够磁盘空间。

顶栏始终显示当前协作状态：在线人数、正在同步原件、自动重连或需要处理的异常。点击标识可查看在线成员、复制邀请或退出协作；重连图标有旋转反馈，系统开启减少动态效果时静止。

移动和改变节点大小时，不必松开鼠标，其他设备就能看到过程；文字输入会随编辑同步，正式连线在连接完成后保存。画布同时显示协作者的光标、选中轮廓、移动／编辑状态和正在拖出的连线，预览不会变成真正的连线。各人视角独立，光标按画布位置映射，屏幕大小不随缩放变化；鼠标离开画布会隐藏光标，切到其他应用、断线或退出后清除临时操作提示。

操作和光标消息使用加密连接即时发送，连续文档变化合并为增量，不等待原始素材读写和完整传输；远端复用未修改的节点与本机媒体地址，避免每次重新处理整个画布。原件未传完时仍可共同移动、编辑和连线，等待同步完成再使用该原件。实际响应取决于双方电脑与局域网状况。

节点、连线、画布标题和节点内的创作数据同步，包括 3D 场景、分镜等。各自的缩放／视角、聊天、账户、API Key、模型选择与任务回执保留本机。独立剪辑窗口中的多轨项目保留本机，导出回画布的成片可共享。第三方节点需要各设备自行安装相应插件。

共享节点不会自动运行模型。协作者需要在自己设备配置模型，并明确点击生成；同一节点如需生成，请先相互确认由谁执行。生成结果完成后共享给其他设备，生成中的本机任务不会交给别的设备恢复或重发。批量任务仍遵循串行与执行前确认规则。

不同字段的并发编辑会合并。节点文字、提示词、备注和节点标题使用 Yjs 字符合并，支持中文和 emoji；标题按原有交互在确认后提交。其他单值字段的冲突会收敛为其中一项，列表和数组作为同一字段处理。协作中的撤销与重做只处理本人本次会话的修改，不回放整张画布覆盖别人；一次拖动／改变大小与下一次操作分开撤销。光标、选中和连线预览不进入存档或撤销记录。删除节点后，其他设备对旧节点的编辑不会把它自动复活。

断线后每 3 秒重连，保持当前文档并在连接恢复后合并；网络恢复或电脑唤醒后会重建加入的连接，不会重发付费请求。之前加入的画布重开时，会自动恢复原房间与同一副本，保留共享文档的合并标识；房主仍需保持房间运行。邀请与共享文档加密保存在本机，不调用系统钥匙串，不进入画布导出或共享内容；同一系统账户能读取本机密钥，不用于防御账户已被入侵的情况。主动退出、切换画布离开协作或收到房主结束通知后清除自动恢复。房主结束协作或退出软件后，各设备保留已经收到的本地副本；原件应在退出前同步完成。房主设备异常关机时，其他人可手动退出等待并保留副本。继续创作需由用户重新共享和发送新邀请，软件重启不会自动开房。

连接失败时先确认双方在同一 Wi-Fi／网线网络，系统防火墙允许 Canvas 访问专用网络，路由器没有开启访客隔离或设备隔离；存在 VPN／虚拟网卡时请更换房间中的邀请地址。不要关闭系统防火墙，也无需将端口映射到公网。浏览器版暂不支持创建或加入原生局域网房间。

连接只在用户共享期间监听动态局域网端口，邀请包含随机认证秘密。握手使用 HMAC 验证双方身份，HKDF 为每次连接派生独立方向密钥，AES-256-GCM 校验消息及顺序；素材按 SHA-256 内容寻址并验证字节，不使用缩略图替代原件。原始图片、音视频和文件仅在加入房间的设备之间传输，按本机既有素材库方式保存。房间临时缓存随正常结束清理；本地画布与已保存的原件保留。

协作者应先更新到同一版本，再创建和分享新的房间邀请。回归入口：`npm run test:collaboration`，验证真实节点控件在松开鼠标前同步拖动／大小、编辑框未失焦时同步文字、不同缩放下的光标／选中／连线预览及退出清理。原生测试刻意暂停原件传输，验证三端操作消息仍能通过；文档测试覆盖中文／emoji 并发合并和仅撤销本人输入。原有原图／文件字节、退出副本、断线恢复和六平台打包冒烟继续执行；另验证加密恢复记录、新服务实例／界面重载后重连同一画布、离线修改合并、在线／断线标识及明确退出后不再恢复。自动化使用隔离数据及模拟素材，不调用真实付费模型；实际跨电脑防火墙、网络环境与长媒体仍需实机确认。
