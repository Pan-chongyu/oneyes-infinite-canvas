# 视频节点快捷工作流

选中已有视频，在快捷工具栏或右键菜单选择「创建反推提示词」或「创建生成配置」。创建操作只添加节点和连线，不调用模型，也不修改原视频。重复创建会避开已有节点。

## 反推提示词

1. 选择「创建反推提示词」，画布添加可编辑的任务文本和文本生成配置，并自动连接原视频。
2. 在生成配置中选择支持图片输入的视觉模型。打开参数面板可调整「每段视频抽帧」，默认沿用导演台的 6 帧设置，保存到当前节点。
3. 点击「开始生成」后，本机按时间顺序抽取原尺寸画面，将帧和对应时间发给选定模型；已有图片参考保持在前，多个视频分别编号。
4. 分析结果流式写入新的文本节点，可继续编辑、复制，或连接到视频生成配置使用。运行时显示抽帧／分析状态，点击运行按钮可按原有确认流程停止。

这是根据抽样画面重建创作描述，不是找回原始提示词；不读取音轨，不应据此确认声音或采样间的完整动作。画面数量越多，发送给视觉模型的图片越多。模型是否支持多图以及实际计费由所选接口决定。

取消、无法解码或原视频缺失时停止提交，保留中文错误；不会自动重新发起付费请求。重启后保留工作流和抽帧设置，仍需用户手动开始。反推连接断开时必须先重新连接原视频。

## 创建生成配置

复制此视频保存的提示词、准确模型／渠道、画幅、分辨率、时长、音频、水印和生成模式，创建提示词文本及待运行的视频配置。不会自动把生成结果当作视频编辑参考，也不会复制旧任务回执、素材存储标识或密钥。

原生成任务保存的参考图、视频和音频仍在画布时，会按原顺序连接到新配置；缺失则提示先恢复素材，不静默丢弃。导入视频没有生成提示词时，新建文本为空，请填写或使用反推结果后再生成。未支持的模型参数组合仍由既有视频能力校验在付费提交前提示，用户选择的分辨率不会自动降低。

## 验证

`npm run test:video-workflow` 使用隔离的真实桌面页面、IndexedDB、原生媒体组件和本机生成的视频样片，验证节点创建、实际帧尺寸与顺序、模型请求、失败／取消、配置复制、原参考素材、重新加载和无自动提交。请求由本机测试响应代替，不调用真实付费模型；六种平台／芯片的发布流程均执行此回归。
