# 智能剪辑节点

在节点库「音视频 → 智能剪辑」添加，或选择「智能剪辑」流程模板。模板只创建节点与连线，不自动执行。连接／选择本地视频、图片、旁白或配乐，可另接文本、分镜脚本与已有「语音转字幕」节点；素材可排序，字幕必须明确对应一个已选视频。

1. 点击「分析素材」，在本机读取原始视频的尺寸、帧率、音轨、静音区间和切镜时间。图片采用设置的展示秒数。
2. 选择「手动剪辑」「口播精剪」「分镜选片」「文字剪辑」或「AI 编排」。手动模式点击「读取素材」整段导入，无需模型；其他本地清单支持语句留白，文字剪辑按可靠的段级字幕生成片段。更换方式／留白不会悄悄覆盖手动编辑，需主动生成新清单。
3. 点击成片顺序中的片段预览。上方滑条／播放头秒数用于定位，下方双端滑条调整保留范围；可点击「设为入点」「设为出点」「在此切分」和「恢复整段」。列表支持精确起止时间、切换素材、复制、排序、保留勾选和添加／删除，并能搜索字幕或选择理由。自动剪辑结果使用同一编辑器；原片预览不包含尚未渲染的效果。
4. 按需展开「分析与成片设置」，设置叠化转场、切口声音淡化、原声／旁白音量、暖色／鲜明调色、顶部标题与中文字幕烧录。转场必须小于各片段时长的一半。
5. 输出成片，生成新的标准视频节点并自动连线，保留原件；也可导出 JSON 剪辑清单或按成片顺序重新计时的 SRT。清单是本节点的可读数据，不是 Premiere／Resolve 工程文件。

## 模型、费用和恢复

本机分析、片段编辑和 FFmpeg 渲染不发模型请求，不上传素材。语音识别需要站点已开通且支持 `verbose_json` 段级时间戳的 OpenAI 兼容模型，识别前说明音轨上传与费用；已有字幕直接复用。只在接口返回可靠说话人字段时保留标注，不推测人物或词级时间。

AI 编排复用当前文本模型渠道，提交前确认费用；仅发送素材名称、字幕、镜头时间和脚本要求，不上传图片／视频，不声称理解未提供的画面内容。模型输出的素材 ID 和时间必须合法，不静默截断越界时间。请求错误／取消不自动重试。字幕与清单编辑保存在现有画布 metadata；退出或重启保留分析和清单，未完成的本地渲染需手动重新输出，已受理的模型请求先核对用量，不自动重发。关闭面板、切换画布、删除节点或改变实际输入会取消本地任务，不能把迟到结果写进别的画布。单纯移动素材不取消任务。

「AI 编排」的模型列表直接读取当前渠道中标记为文本的模型，显示「渠道 / 模型」，即使多个渠道同名也分别选择。保留渠道限定 ID、对应 Key 和既有调用方式／自定义脚本，不改动 Claude 接口。未指定时显示当前默认文本模型，提交确认会显示实际使用的模型；选定或默认模型已删除、类型不匹配、Key 未配置时阻止请求，可直接打开「模型设置」修复，不自动替换成其他模型。生图、视频、语音和 JEV 决策模型不会当作文本模型使用。站点实际开通情况和模型是否能返回有效剪辑清单仍由上游决定；不重放失败请求。

手动修改片段和重新生成清单支持本次面板会话内的撤销／重做；重新读取素材或更新字幕后重置撤销历史。关闭或重启后恢复最新保存的清单，不恢复撤销栈，也不调用模型。切分保留来源、字幕映射和原始时间，不覆盖原片；转场长度不适合新短片段时会提示用户调整，不静默改变设置。

## 媒体约束

- 复用已随桌面安装包分发的 FFmpeg、FFprobe 和 Noto 中文字体，无需另装 Python、CUDA 或剪辑服务；浏览器版会提示使用桌面版。
- 成片保留所选画面的原始像素尺寸；不自动缩小、裁切、升采样或更换模型。当前拼接要求画面尺寸、固定视频帧率、像素比例及有声音轨结构一致；不一致会要求用户主动统一。图片跟随所选视频帧率，纯图片使用 30 fps。
- 视频保留全部音轨；无声片段补对应静音轨，旁白／配乐混入各原音轨。口播去静音必须所有音轨都安静才删除；完全无音轨的视频不能当成静音自动删除，可使用其他方式。
- 本机渲染为 H.264／AAC MP4（有损编码），保持尺寸不等于逐像素无损。奇数尺寸使用支持相应尺寸的像素格式。当前不承诺 HDR／高位深、色彩管理、自动素材检索、自动配音或专业多轨时间线。
- 上传只接受自包含媒体。路径和程序由主进程生成，不执行用户命令、脚本、外部播放列表或文件路径；停止与完成后清理任务临时文件。输出重新核对尺寸、音轨和时长。

## 验证

发布流水线在六种平台／芯片执行真实 FFmpeg 合成素材回归及 `npm run test:smart-edit`。原生协议使用隔离存储、实际 IPC 上传／取回，覆盖无模型的手动裁剪／切分／复制／排序／撤销重做与渲染、准确的模型渠道选择、模型／Key 缺失拦截、AI 清单继续手工编辑和跨进程恢复，以及字幕复用、取消、模型失败不重发、输入变更与跨画布隔离；模型为 fixture，不调用付费服务。实际长视频、复杂编码和真实语音模型效果仍需用户测试。
