# OneYes 智能剪辑

智能剪辑已由原有自研面板替换为真正迁移的 [Velocut](https://github.com/open-ribbi/velocut) 编辑器。固定源码提交、MIT 原文及本地修改说明见 vendor/velocut/ONEYES.md。它随桌面安装包分发，无需额外安装网页服务。

## 使用

1. 在原画布添加「智能剪辑」节点，连接视频、图片、音频，点击「打开剪辑器」。也可先开空项目，再导入本机文件。
2. 素材库点击加号或拖到时间线。支持多轨、分割、修剪、移动、变速、音量、文字、调色、效果、转场和关键帧；可以撤销、重做和查看历史。
3. AI 助手选择 Canvas 已有文本模型，说明剪辑要求，点击「生成剪辑草稿」。检查说明与操作数量，确认后「应用到时间线」，再继续手动精修。调用沿用现有渠道（包括其 Claude 接口），不会复制 Key 到独立窗口。
4. 点击导出，可回填原画布为独立视频节点，也可保存 MP4 文件。关闭编辑器后从同一节点重新打开，可恢复本机时间线、原始素材与历史。

## 数据和模型

每个画布节点有独立本机项目。原始媒体保存在 OPFS，时间线与历史保存在 IndexedDB，同名文件按独立 ID 保存。关闭或退出前等待持久化；失败提示返回重试，不把失败当成保存成功。本轮不提供剪辑项目 WebDAV／跨设备同步；回填的视频仍使用画布已有媒体与同步链路。旧自研剪辑清单不自动转换成新时间线，原素材和画布保留。

AI 仅接收用户要求、时间线结构和素材名称，不上传视频、音频、Key、本机路径或三维脚本。因此能按指令编排，但不能声称已经识别画面、人声或静音。没有文本模型时可正常手剪。模型失败、取消和软件重启均不自动重发付费请求。原画布关闭或切换后需从原节点重建 AI 连接。

草稿使用上游真实编辑命令，先在隔离引擎校验，再整批应用。来源替换、外部下载、任意脚本、修改分辨率和超出原素材时长均拒绝；时间线已经改变则要求重新生成草稿，不能覆盖用户手动修改。

## 输出条件

项目初始画幅采用首个已连接图像／视频的原始尺寸；空项目默认 1920 × 1080，可通过「画面尺寸」主动修改。导出始终使用项目精确尺寸，不会为适配硬件自动降分辨率。WebGPU、WebCodecs 及所选编码必须受本机支持，不支持时给出提示并保留设置。音频输出为立体声 AAC 混音，变速会同时改变音调，不属于保持音调的专业时间拉伸；多声道、复杂素材和长视频需要实机验收。

上游三维素材的来源和许可随包放在 editor/scene-assets/LICENSES.md，MIT 与依赖许可放在 editor/licenses。未启用上游 Codex 配对、默认外部 AI 账户、云代理或生成占位功能。

## 验证

发布运行 test:editor（真实命令与草稿校验）及 test:smart-edit（独立 Electron 窗口、受控 IPC、真实生产资源和原生协议、同名媒体、AI 确认／撤销／重做、MP4 原尺寸与音频、跨进程恢复）。使用合成媒体与隔离模型，不发送真实付费请求。没有可用 WebGPU 的 CI 会明确报告未验证渲染，不能通过降尺寸替代验收。
