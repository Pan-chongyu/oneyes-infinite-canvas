## 应用摘要

将图片、视频、文字、3D 预演与 AI 助手连接成可复用的创作流程，适合海报设计、分镜规划、短片制作、漫剧与团队共创。

## 官方介绍

OneYes Canvas 是面向视觉创作者的开源无限画布工作台。把灵感、提示词、参考素材、AI 生成结果和后期处理放在同一个项目中，用节点与连线组织创作过程，从一个想法逐步推进到图片、分镜和视频作品。

适合用来做什么
• 设计与出图：收集参考图、制作产品主图与海报、探索角色和场景风格，对比多版结果并持续修改。
• 分镜与短片：整理脚本、设计人物站位和镜头、生成视频素材，再进入剪辑窗口完成时间线编排。
• 漫剧与故事创作：把故事、角色设定、场景参考和分镜连接起来，复用已有素材与生成配置。
• 团队方案共创：在同一局域网共享画布，共同整理素材、调整节点和讨论镜头方案。

核心功能与用途

1. 无限画布与素材组织
将图片、视频、音频和文字拖入画布，按项目、分组和连线整理内容。支持缩放、小地图、批量复制、撤销重做和一键整理节点；空白处右键可粘贴剪贴板中的图片、图片文件或文字，快速建立素材板。

2. 生成配置与模型接入
把文本和参考素材连接到生成配置节点，或通过 @ 引用指定素材。选择当前 Key 可用的模型及参数，复用同一套流程生成不同方案；视频模型可保存各自的默认配置，减少重复设置。

3. AI 图片创作
支持文生图、参考图编辑与多图引用，可在画布内查看结果并接着迭代。按模型接口支持流式预览或异步任务取回，原图保存后即可显示；已取得可靠任务回执时，断网或重启后可继续查询和取回结果。

4. AI 视频创作
通过文字、图片及模型支持的其他参考素材生成视频，按所选模型设置时长、画幅和分辨率。结果直接成为视频节点，可播放、全屏查看，并继续用于分镜分析或剪辑。

5. 3D 导演台
用提示词或连接的参考生成布景与动态预演，再手动微调人物、道具、姿态、灯光和机位。通过分镜与关键帧设计镜头，导出取景图、分镜包或 PNG 序列，帮助在正式生成前明确构图、站位和动作。

6. 智能剪辑与人工精修
从画布节点打开独立多轨剪辑窗口，完成修剪、分割、变速、文字、转场和关键帧编辑。可先由 AI 提供剪辑草稿，确认后应用，再手动调整；导出成片后回到画布继续使用。

7. 视频反推提示词
提取视频参考帧，使用视觉模型分析场景、主体、动作、镜头和时间段，生成可编辑的详细提示词，并继续创建生成配置或分镜，方便学习镜头表达和制作相近风格的方案。

8. 图片与影音处理
通过扩展节点进行抠图、图层合成、拼图、分镜板、调色与色彩匹配、图片超分、视频超采样、拼接、配乐和混音，将生成后的素材接入后期处理流程。

9. Agent 创作助手
接入 Codex 或 Claude Code，在侧栏对话、查看执行进度并审批操作；通过 MCP 读取与操作当前画布。支持一键配置 Codex 接入，让助手结合画布中的内容协助创作。

10. 实时协作、同步与扩展
同一局域网的成员可共同编辑画布，查看彼此的光标、选中节点与操作状态，断线后自动重新连接。素材可重复使用，也可配置 WebDAV 同步；支持拖入节点插件安装，并提供文档与 SDK 开发自定义节点。

模型能力以当前账号与 Key 实际可用的模型为准；参考素材、时长和输出规格随模型变化。3D 动画预演用于构图与镜头设计，最终 AI 视频由所选视频模型生成。

## 使用说明

开始使用
1. 安装适合本机系统与芯片的版本。Canvas 可以独立安装和使用，无需 OneYes Desktop 常驻。
2. 打开“配置与用户偏好”，登录 OneYes 后一键配置模型，或手动填写 API Key。已登录 OneYes Desktop 时可复用登录状态。
3. 新建画布，拖入图片、视频或音频；也可在空白处右键粘贴图片、图片文件或文字。
4. 添加生成配置节点，用连线或 @ 引用素材，选择模型并确认参数后生成。结果可以继续作为下游节点的参考。
5. 需要规划镜头时使用 3D 导演台；需要编排成片时打开智能剪辑。完成后保存项目，导出素材或作品。

示例流程
产品海报：参考图片 → 提示词与生成配置 → 生成多版图片 → 合成与调色 → 导出。
分镜短片：故事与角色参考 → 3D 布景／镜头预演 → 视频生成 → 多轨剪辑与配乐 → 导出成片。

保存与协作
画布、素材与剪辑项目默认保存在当前设备，WebDAV 是可选同步方式。局域网协作同步共享画布和素材，不向协作者共享账号或 API Key；独立剪辑窗口的时间线保存在本机，导出的成片可回填共享画布。

生成任务与模型使用
AI 生成需要可用的账号或 API Key，费用按所选模型与站点规则计算。已有可靠回执的任务可继续查询取回，不会因重启自动重新提交付费请求；未取得回执时保留核实入口。模型支持的素材、尺寸和参数以界面实际能力为准。

系统与更新
支持 Windows、macOS、Linux 的 x64／ARM64 平台。桌面版内置 OTA 更新，提供更新进度、文件校验和安装后重新打开。macOS 当前安装包为自签名版本，尚未经过 Apple 公证。
