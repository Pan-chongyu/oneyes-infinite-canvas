# Canvas 错误日志检查

## v0.20.89

本轮检查管理平台已接收的脱敏技术日志，并用 v0.20.83 正式 macOS 安装包反查压缩代码位置；包的 SHA-256 与 GitHub 发布摘要一致。最新记录主要来自 v0.20.83，未将旧版日志当作 v0.20.88 新回归。

| 记录 | 定位与处理 |
| --- | --- |
| Windows renderer TypeError，`index-DM4BdD0X.js:5325:35501` | 同版本 macOS 对应代码是侧栏 `onMouseLeave` 对 `relatedTarget.closest()` 的调用。移出窗口时 relatedTarget 可为 Window，不能按 Element 强制断言。列表与网格均增加真实类型检查；模拟 Window、Document、null、普通元素和相邻节点验证清除／保留悬停。 |
| Grok 视频提交 422 | 当前客户端忽略 FastAPI 风格的 detail 数组，只显示状态码。现在解析 loc／msg，标出字段并提示调整参数，不读取 input，不改变已选参数、不重发。HTTP 422 在诊断中归为 invalid-data。没有原始响应正文，不能断言具体哪个参数被站点拒绝。 |
| 视频提交／查询 404 | 未认证的两个域名 `/v1/videos/generations` 与直连 `/v1/videos` 探测均返回要求 Key 的 401；仅能确认入口受鉴权保护，不能确认某个账号／分组的模型路由。界面提供模型、Key 分组和站点结果核对提示，不切换路由或重放付费 POST。 |
| 模型目录 permission、status 0 | 原生模型目录错误只有中文消息，没有结构化 HTTP 状态。现在保留实际状态和网络 cause，日志继续只输出白名单状态／代码／堆栈，不输出 Key、请求或响应。 |
| 旧版 OTA install/network | v0.20.83 的诊断以友好文案重建异常，不能据此判断实际安装失败原因。v0.20.86 起已保留真实原因、操作分类和安装回执；本轮不把这些历史记录冒充已复现或已恢复，也不删除它们。 |

检查未调用付费生成接口，未读取用户提示词、媒体或密钥。保留原有 60 秒合并上传、1000 条加密队列与后台 30 天保留规则；仅已有的精确恢复回执可清理对应记录。新增回归复用六平台发布中的 `npm test`、`npm run test:plugins` 与前端类型检查。
